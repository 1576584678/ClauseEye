# ClauseEye（契眼）产品方案 · PRD

> 版本：v0.1 · 状态：方案设计 · 最后更新：2026-09-17

---

## 1. 背景与机会

### 1.1 市场现状
- **企业级合同审查是红海**：海外有 Kira(Litera)、Ironclad、Harvey、Spellbook、Luminance、Evisort；国内有幂律（吾律）、法大大 iTerms Pro、MetaLaw、通义法睿、法行宝等。客户是法务部，销售周期长、客单价高。
- **个人 / 消费级是空白**：普通人每年都要面对劳动合同、租房合同、离职证明、工伤鉴定、多份 Offer，但国内**没有任何产品**做成"长期文档沉淀 + 自动分类 + 跨文档对比"的闭环。现有产品多为：
  - 单次审查 chatbot（腾讯电子签 AI、阿里通义法睿、秘塔 AI）；
  - 法律任务交付工具（吾律：立案 / 律师函 / 仲裁，非文档管家）；
  - 模板生成（合同宝、华律网）。
- 海外已有消费级雏形（Vikk AI、ContractRev、Mantle Clerk、MAIN AI、GoHeather），但**只做美国法、单次报告**，且未做"个人文档库 + 多 Offer 对比"。

### 1.2 机会判断
做"**个人合同 & 证明文档管家**"这个消费级切口，在国内是真实空白，且具备差异化空间。

## 2. 产品定位

| 项 | 内容 |
|---|---|
| 一句话 | 隐私优先的个人合同与证明文档管家 |
| 核心场景 | 导入合同/证明 → 自动分类 → AI 标坑 → 多 Offer 对比 |

- 英文：**ClauseEye**

## 4. 核心功能清单（MVP → v1 → v2）

### MVP（本地优先骨架）
1. **文档导入**：支持 PDF / Word / 图片（OCR），拖拽或选择导入。
2. **自动分类**：识别类型（劳动合同 / 租房 / 离职证明 / 工伤鉴定 / Offer / 其他）并归入"保险箱"。
3. **本地加密存储**：SQLite + 文件系统，密钥在本地。
4. **坑点清单**：对单份文档输出结构化风险条目（高/中/低 + 原文引用 + 通俗解释）。
5. **多 Offer 对比**：上传 ≥2 份 Offer → 结构化字段抽取 → 并排对比矩阵 + 简评。

### v1（智能化增强）
6. **BYOK 深度分析**：用户填自己的模型 Key，调用强模型做深度审查（我们零接触）。
7. **到期 / 续约提醒**：从合同中抽取关键日期，本地定时提醒。
8. **中国法知识库 + 规则库**：内置高频坑点规则（如试用期超 6 个月、违约金过高、自动续约陷阱）。

### v2（生态与增值）
9. **律师人工复核转介**（增值，抽佣）。
10. **跨设备私有同步**（可选，用户自建或使用自身云盘）。
11. **证据链整理**：围绕一次纠纷自动归集相关文档。

## 5. 关键用户流程

### 5.1 单文档审查流
```
导入文档 → 本地 OCR/解析 → 自动分类
  → 本地规则引擎初筛（快、离线）
  → [可选 BYOK] 强模型深度分析
  → 输出「坑点清单 + 修订建议 + 风险等级」
  → 结果回写本地，永不外传
```

### 5.2 多 Offer 对比流
```
上传 Offer A/B/C → 结构化抽取（公司/薪资/期权/试用期/地点/违约金/福利）
  → 生成对比矩阵
  → 给出「综合建议」（哪份更优、各自短板）
  → 全部留存在本地保险箱
```

## 6. 差异化与护城河

1. **隐私即卖点**：本地优先 + BYOK，区别于所有云端对手（腾讯/阿里/吾律），直接回应"信息泄漏"顾虑。
2. **数据资产壁垒**：中国本地合同模板库 + 坑点规则库 + 多 Offer 结构化对比口径——这三样是越用越值钱的数据资产，难以被通用大模型复制。
3. **消费级闭环**：从"单次审查"升级为"长期文档管家"，提升留存（个人签合同虽低频，但文档沉淀带来长期价值）。

---

## 7. 隐私与合规模型

- **绝不提供有约束力的法律意见**：所有输出标注「AI 辅助，非律师意见，重大决策请咨询专业人士」。
- **零数据持有**：本地存储；BYOK 模式下合同仅发往用户指定的模型厂商。
- **可验证**：提供"离线模式"开关，关闭后即纯本地运行。

## 8. 商业模式

| 模式 | 说明 | 适配度 |
|---|---|---|
| **买断 / 终身制** | 一次性付费，契合"我们不持有你数据"叙事 | ★★★ 推荐主力 |
| 免费本地版 + 增值 | 基础免费，律师复核 / 云同步 / 多设备收费 | ★★ 可并行 |
| 订阅 | 卖持续更新的云能力 | ★ 与隐私叙事弱冲突，谨慎 |

> 注：BYOK 模式下模型调用成本由用户承担，规避了纯买断的推理成本压力。

## 10. 里程碑 / 路线图

- **M1（4–6 周）**：本地优先 MVP 原型——导入/分类/本地规则坑点清单/多 Offer 对比。
- **M2（8–10 周）**：BYOK 深度分析 + 到期提醒 + 中国法规则库 v1。
- **M3（Q1 后）**：买断版上架（官网/小程序外链）+ 律师复核增值。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 坑点检测准确率不足（幻觉） | 规则引擎保底 + RAG 法条 + 人工复核回路 + 风险分级标注 |
| 个人付费意愿低 | 买断制 + 免费本地版 + 律师转介抽佣 |
| 留存难（低频） | 文档沉淀 / 提醒 / 对比，做"管家"而非"工具" |
| 合规红线 | 全程"非法律意见"声明 + 离线可验证 |
